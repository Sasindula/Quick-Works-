🚀 **Diploma Final Project – QuickWorks**

I’m excited to share my **Diploma Final Project – QuickWorks**, a service booking platform developed as part of my Software Engineering journey. 💻✨

**QuickWorks** is designed to connect customers with service workers and make the process of finding, booking, and managing services easier and more efficient.

🔹 **Key Features:**
• Customer & Worker interaction
• Worker search and profile management
• Job/service booking system
• Real-time time-slot availability
• Booking status management
• Booking notifications
• Payment method selection
• Booking summary with estimated cost
• Responsive and user-friendly interface

🛠️ **Technologies Used:**
• PHP
• MySQL
• HTML5
• CSS3
• JavaScript
• Bootstrap 5
• REST-style API requests using Fetch API

This project gave me valuable hands-on experience in **web application development, database management, backend logic, frontend development, system design, and problem-solving**.
